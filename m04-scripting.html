2. Bash

Ideal para encadenar comandos de Linux. Ejemplo clásico: descubrir qué equipos responden en una red.

#!/bin/bash
# ping_sweep.sh — uso: ./ping_sweep.sh 192.168.1
red=$1
for host in $(seq 1 254); do
  ping -c 1 -W 1 "$red.$host" > /dev/null 2>&1 && echo "[+] $red.$host está activo" &
done
wait
  1. #!/bin/bash (“shebang”) indica qué intérprete usar.
  2. red=$1 guarda el primer argumento.
  3. El bucle recorre del 1 al 254.
  4. ping -c 1 -W 1 envía un solo ping con 1 s de espera; la salida se descarta.
  5. && echo solo imprime si el ping fue bien. El & final lo lanza en paralelo; wait espera a todos.

3. Python

El lenguaje en el que están escritos muchísimos exploits y herramientas públicas. Debes saber leerlo y ejecutarlo.

#!/usr/bin/env python3
# comprobar_web.py — comprueba qué rutas existen en una web de tu laboratorio
import sys
import requests

url = sys.argv[1]
rutas = ["admin", "login", "backup", "uploads"]

for r in rutas:
    resp = requests.get(f"{url}/{r}", timeout=5)
    if resp.status_code != 404:
        print(f"[+] /{r} -> {resp.status_code}")
LíneaExplicación
import requestsCarga la librería para hacer peticiones HTTP
sys.argv[1]El primer argumento que pasas al ejecutar
f"{url}/{r}"“f-string”: mete variables dentro del texto
Sangría (espacios)En Python la sangría define los bloques. Si la estropeas, falla

5. Leer y adaptar código público

En el OSCP usarás exploits publicados (Exploit-DB, GitHub). Casi nunca funcionan a la primera: hay que leerlos y adaptarlos.

  1. Lee el código entero antes de ejecutarlo. ¿Qué hace? ¿Hay algo destructivo? ¿Se conecta a algún sitio que no esperas?
  2. Busca las variables a cambiar: IP objetivo, puerto, tu IP (LHOST), rutas, usuario/contraseña.
  3. Comprueba la versión de Python: print "x" sin paréntesis = Python 2. Conviértelo o usa python2.
  4. Comprueba la versión del software objetivo: el exploit suele servir solo para versiones concretas.
  5. Instala dependencias en un entorno virtual.
  6. Prueba y depura: lee los errores, añade print() para ver qué pasa.
Nunca ejecutes a ciegasHay “exploits” falsos en GitHub que atacan al que los ejecuta. Leer el código no es opcional: te protege y te enseña.

Media Generador de contraseñas candidatas

Con Python, a partir de una lista de palabras (empresa, ciudad…) genera variantes añadiendo los años 2023–2025 y un “!” al final. Útil para auditar contraseñas débiles en tu lab.

palabras = ["Corp", "Madrid", "Verano"]
for p in palabras:
    for anio in range(2023, 2026):
        print(f"{p}{anio}")
        print(f"{p}{anio}!")
Media Detecta Python 2

¿Qué líneas de este fragmento delatan Python 2 y cómo las corregirías?

print "[*] Conectando a", host
data = raw_input("Comando: ")
except Exception, e:

Solución: las tres. En Python 3: print("[*] Conectando a", host), input("Comando: "), except Exception as e:. Ojo también con cadenas/bytes al usar sockets: en Python 3 hay que hacer .encode().

Reto Extrae puertos de nmap

De un archivo scan.nmap con líneas como 22/tcp open ssh, obtén una lista de puertos separada por comas (para pasarla a otro escaneo).

grep "/tcp" scan.nmap | grep open | cut -d/ -f1 | paste -sd,

Resultado típico: 22,80,445. paste -sd, une las líneas con comas.
