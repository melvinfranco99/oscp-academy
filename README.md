# OSCP Academy

Curso web visual, en español y desde cero, para preparar la certificación **OSCP / OSCP+** de OffSec.

Incluye 16 módulos (de fundamentos de informática hasta Active Directory, pivoting, reporte y estrategia de examen), con diagramas animados, tablas, analogías, terminales interactivas, más de 250 preguntas de autoevaluación con solución, un glosario con buscador, una plantilla de reporte descargable y un simulacro cronometrado.

## Contenido
- **Nivel 1 · Bases:** fundamentos, Linux, Windows, redes, scripting.
- **Nivel 2 · Pentesting:** metodología, enumeración, web, explotación, contraseñas.
- **Nivel 3 · Nivel OSCP:** escalada en Linux y Windows, Active Directory, pivoting.
- **Nivel 4 · Examen:** cómo hacer el reporte, plantilla, estrategia y simulacro.
- **Referencia:** glosario/comandos y recursos (vídeos, labs, documentación).

## Uso
Abre `index.html` en el navegador, o visita la versión publicada en GitHub Pages.

## Aviso
Material exclusivamente educativo. Todas las técnicas se practican **solo** en laboratorios autorizados (PEN-200, Hack The Box, TryHackMe, Proving Grounds, VulnHub) o en sistemas propios. El acceso no autorizado a sistemas ajenos es delito.
